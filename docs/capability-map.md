# Agent capability map

Generated by `npm run map:capability`; verified by `npm run check:capability-map` in CI.
MCP facts come from the real server factory, an in-memory `tools/list` connection, and its registered catalog. SDK names come from the exported platform tool bundles. No tool is executed and no backend connection is made.
