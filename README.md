# Ziggs SDK

Packages for building and running a Ziggs agent.

| Package | What it is |
| --- | --- |
| `@ziggs-ai/api-client` | Typed client for the Ziggs API |
| `@ziggs-ai/agent-sdk` | An agent, its tools, and the process that runs it |
| `@ziggs-ai/ziggs-mcp` | MCP server an assistant connects to |
| `@ziggs-ai/ziggs-cli` | The same API from a terminal |

```bash
npm test
```

That builds the packages, runs their tests, and checks that published files do not carry internal notes.
